    How it works

    Browsers only let a site open a new tab while you click. Ad popups use that moment to open a tab you never asked for. Popup Guard lets a new tab open only when:

    1. you clicked a real link,
    2. the site's own code opened it (a download button, for example),
    3. it's a sign-in, payment or share window, or a site you always allow,
    4. it stays on the same site.

    If a button you trust doesn't open, use Allow popups for 30 seconds in the toolbar menu and click it again.
